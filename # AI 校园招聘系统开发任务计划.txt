# AI 校园招聘系统开发任务计划

## 任务概览

本任务计划将现有 HTML 项目迁移到 Vue 3 技术栈，并设计一套完整的 AI 校园招聘系统界面，包含前台平台端和后台管理端的左右分屏展示。

---

    - 1.3: 配置 Vue Router（hash 模式）

## 注意事项

1. **任务执行顺序**: 按照任务编号顺序依次执行，每个任务完成后才进入下一个
2. **组件复用**: 尽量创建可复用的通用组件
3. **样式一致性**: 遵循 Tailwind CSS 设计规范和项目配色方案
4. **数据模拟**: 所有数据使用模拟数据，暂不涉及真实 API
5. **代码质量**: 保持代码简洁、可读、易维护
