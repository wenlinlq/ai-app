# AI 校园招聘系统完整界面设计 - 需求文档

## 项目概述

设计一套面向校园场景的 AI 校园招聘系统完整界面，主要服务于校园内的技术团队、学生社团、工作室等组织的招新需求。包含前台平台端（学生/求职者视角）和后台管理端（团队负责人/HR 视角），采用左右分屏布局展示。

## 技术栈

- **前端框架**: Vue 3 (使用 Vue CLI 或 Vite 创建)
- **UI 框架**: Tailwind CSS
- **图标库**: Material Icons 或 Heroicons
- **图表库**: ECharts 
- **路由**: Vue Router（使用 hash 模式）
- **状态管理**: Pinia（可选）

## 功能需求

### 一、前台平台端（求职者视角）- 左侧区域

#### 1.1 职位搜索栏
- 搜索输入框：支持关键词搜索（职位名称、团队/社团/工作室名称、技术栈、兴趣方向）
- 组织类型下拉选择：技术团队、学生社团、工作室、实验室、其他
- 招聘类型下拉选择：校园招新、项目招募、实习岗位、志愿者
- 所属院系下拉选择（可选）
- 搜索按钮
- 热门搜索标签展示（如：前端开发、数据科学、算法竞赛、摄影协会等）

#### 1.2 职位推荐列表
- 每个招新卡片展示：
  - 职位/岗位名称和团队/社团/工作室名称
  - 所属院系、年级要求、专业要求
  - 招聘人数和截止日期（高亮显示）
  - **AI 匹配度标签**（如：匹配度 95%、高匹配、中等匹配）
  - 技能/兴趣标签（前端、Python、算法竞赛、摄影、活动策划等）
  - 团队/职位描述摘要（2 行）
  - 发布时间和已报名人数
  - 收藏和报名按钮

#### 1.3 AI 简历优化助手对话窗口
- 聊天界面布局
- AI 侧边栏或浮窗
- 消息气泡样式（用户消息、AI 消息）
- 输入框和发送按钮
- 快捷操作建议（优化简历、调整格式、补充技能）

#### 1.4 面试预约日历
- 月视图日历组件
- 显示已预约的面试时间（标记不同状态）
- 可选择日期进行预约
- 预约信息展示（公司、职位、时间）

#### 1.5 申请进度追踪模块
- 进度条或时间轴展示
- 各阶段状态：简历投递 → AI 筛选 → HR 审核 → 面试安排 → 面试 → Offer 发放
- 每个阶段显示状态（进行中、已完成、待处理）
- 显示每个阶段的详细信息和时间

### 二、后台管理端（HR/管理员视角）- 右侧区域

#### 2.1 顶部数据统计卡片
- 招新岗位发布数（数字 + 环比增长）
- 报名学生总量（数字 + 环比增长）
- 面试/考核通过率（百分比 + 环比变化）
- 当前待审核申请数

#### 2.2 左侧导航栏
- 招新管理
- 报名库
- AI 智能筛选
- 面试/考核安排
- 数据看板
- 系统设置

#### 2.3 候选人列表
- 表格或卡片展示
- 每个候选人显示：
  - 基本信息（头像、姓名、学号、院系专业、年级）
  - **AI 评分**（综合分数，如 85/100）
  - **智能标签**（如：高潜力、技术优秀、有竞赛经验、社团活跃）
  - 报名时间
  - 当前状态（待审核、已筛选、面试/考核中、已录取）
  - 操作按钮（查看详情、发送面试/考核邀请）

#### 2.4 AI 面试/考核评估摘要卡片
- 展示候选人的 AI 面试或作品评估结果
- 评分维度：
  - 技术能力（适用于技术团队）
  - 沟通表达
  - 创新思维
  - 团队协作
  - 特长展示（适用于社团/工作室）
- AI 评价摘要文本
- 推荐建议（推荐录取、待定、不推荐）

#### 2.5 招新漏斗图
- 使用图表展示招新流程各阶段的数据
- 阶段：浏览岗位 → 报名投递 → AI 筛选 → 审核 → 面试/考核 → 录用 → 加入
- 显示各阶段的数量和转化率
- 支持交互查看详情

#### 2.6 全局设置面板
- AI 模型参数配置
  - 筛选阈值设置
  - 评分权重调整
  - 关键词匹配度
- 审核规则配置
  - 自动审核开关
  - 人工审核流程
  - 通知设置

### 三、AI 智能匹配模块（两端联动）

- 显示 AI 匹配的核心流程
- 数据流向可视化
- 两端数据同步状态
- 匹配算法展示（简化版）

## 界面设计规范

### 配色方案
- **主色调**: 深蓝灰 (#1e293b, #334155, #475569)
- **辅助色**: 白色 (#ffffff)
- **强调色**: 蓝色系 (#3b82f6, #2563eb) 或 绿色系 (#10b981) 用于高亮
- **背景色**: 浅灰 (#f8fafc, #f1f5f9)

### 设计风格
- **圆角卡片**: 统一使用 rounded-xl 或 rounded-2xl
- **阴影**: shadow-sm, shadow-md, shadow-lg 层次分明
- **间距**: 统一使用 4 倍数系统（gap-2, gap-4, gap-6 等）
- **字体**: 系统默认字体，标题使用 font-bold，正文使用 font-medium

### 布局
- **整体布局**: 左右分屏（50% - 50%）
- **响应式**: 小屏幕切换为 Tab 标签切换
- **固定高度**: 整个页面高度固定，内部滚动
- **标注**: 使用虚线框和标签标注关键功能区域

## 数据流说明

### 前台 → 后台数据流
- 学生报名投递 → 后台候选人库新增
- AI 匹配评分 → 两端同步显示
- 面试/考核预约 → 后台面试安排更新

### 后台 → 前台数据流
- 负责人发送面试/考核邀请 → 前台收到通知
- 录用通知发送 → 前台状态更新
- AI 筛选结果 → 前台匹配度显示

## 实现细节

### Vue 3 项目初始化
```bash
npm create vue@latest ai-recruitment-system
cd ai-recruitment-system
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

### 组件开发优先级
1. 主布局组件（AppLayout.vue）- 实现左右分屏
2. 前台平台端核心组件
   - 职位搜索栏
   - 职位推荐列表（带匹配度标签）
3. 后台管理端核心组件
   - 数据统计卡片
   - 候选人列表（带 AI 评分）
   - AI 面试评估卡片
4. 辅助组件
   - AI 对话窗口
   - 日历组件
   - 招聘漏斗图
   - 全局设置面板

### 路由配置
- 使用 hash 模式（方便直接打开 HTML 文件）
- 默认路由显示左右分屏
- 可选：独立的前台和后台路由

## 边界条件与异常处理

- 暂无真实后端 API，使用模拟数据
- 图表使用静态数据或简单随机数据
- 响应式处理：小屏幕下隐藏分屏，改为 Tab 切换
- 加载状态：展示骨架屏或加载动画
- 场景限定：校园内部招聘，不涉及薪资、工作地点等传统招聘元素

## 预期成果

- 完整的 Vue 3 项目
- 可直接运行的前端界面
- 左右分屏展示前台和后台
- 所有核心功能模块可视化
- 适合产品演示和设计评审
- 标注关键功能区域

## 备注

- 本项目为界面原型设计，重点在视觉呈现和交互体验
- 使用模拟数据，不涉及真实业务逻辑
- 所有交互效果使用 Vue 响应式和 CSS 动画实现
- 遵循 Tailwind CSS 最佳实践
- 应用场景：校园内技术团队、学生社团、工作室等组织的招新活动
- 目标用户：在校学生（求职者）、团队负责人/社团干部（管理员）
